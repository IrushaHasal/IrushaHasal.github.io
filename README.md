# qbit short link

Static GitHub Pages redirect for the qbit seedbox.

- `https://irushahasal.github.io/qbit/` → Modal deployment
- `https://irushahasal.github.io/` → `/qbit/`
- Unknown paths under `/qbit/` are forwarded to the same path on Modal.

The target is set in `qbit/index.html` and `404.html`.
